# Exames Resolvidos - ASI

Estrutura organizada por exame e alíneas:

## 📁 `exame 1/` (Exame Modelo)
- `ex1.py`: Validação de IP CIDR
- `ex2.py`: Validação de Data e Hora
- `ex3.py`: Validação de Pessoa e Idade
- `ex4a.py` / `Leitura.py`: Função `ler`
- `ex4b.py` / `Apurar.py`: Função `acumulado`
- `dados.txt`

- `ex1.py`: Ofuscação com SHA256

- `ex2b.py` / `Check.py`: Função `bckSuccess`
- `ex2c.py` / `Average.py`: Função `AverageBackupTime`
- `ex2d.py` / `Stats.py`: Funções `TotalBackups` e `TotalFailed`
- `backup.txt`

## 📁 `exame 3/` (Teste B — 2025/2026)
- `ex1.py`: Anonimizador de logs
- `ex2a.py` / `ReadLogFile.py`: Função `Read`

- `ex2c.py` / `Average.py`: Função `AvarageMethod`

- `acessos_servidor.txt`

- `ex1.py`: Ofuscação de NIFs com Regex

- `ex3b.py` / `ex3c.py` / `Stats.py`: Funções `Control` e `MenorMedia`
